# Evidencia de ejecución

La guía solicita dos capturas por checkpoint (26 imágenes). No se incluyen imágenes sintéticas ni capturas que no se hayan obtenido de una ejecución real. En esta entrega se encuentran pendientes de captura los checkpoints 1–13.

| Checkpoint | Evidencia esperada | Estado |
|---|---|---|
| 1 | `post1.com`: copia MOVSB y MOVSW | Pendiente |
| 2 | comparación de ambas copias / longitud impar | Pendiente |
| 3 | `post1c.com`: coincidencia y búsqueda negativa | Pendiente |
| 4 | `post1d.com`: cadenas iguales y diferentes | Pendiente |
| 5 | `post1e.com`: transformación a mayúsculas | Pendiente |
| 6 | README: dos decisiones técnicas de la Parte 1 | Pendiente |
| 7 | `post2.com`: suma de 32 bits | Pendiente |
| 8 | `post2.com`: resta de 32 bits | Pendiente |
| 9 | `post2b.com`: DAA, DAS y acarreo | Pendiente |
| 10 | `post2c.com`: multiplicación, división y división por cero | Pendiente |
| 11 | `post2d.com`: AAA y AAS | Pendiente |
| 12 | README: decisión DAA/DAS frente a AAA/AAS | Pendiente |
| 13 | README: decisión ADC fijo frente a bucle | Pendiente |

Guardar cada captura auténtica aquí con un nombre que identifique checkpoint y variante, por ejemplo `cp01-a.png` y `cp01-b.png`.
